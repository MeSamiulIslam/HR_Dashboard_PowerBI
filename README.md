# Analyse HR data and created an interactive dashboard using Power BI.

Project Learnings:

1. Created interactive dashboard to track and analyze employee attrition and workforce insights
2. Used filters and slicers to drill down by department, gender, job role, education, salary slab, and age group
3. Built relationships, applied calculations, and developed measures to calculate attrition rate, average age, average salary, and average years of service
4. Designed customized visualizations (bar chart, donut chart, line chart, clustered bar chart, KPI cards, etc.) to highlight key HR metrics and attrition patterns
